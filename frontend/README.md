# Frontend

React timeline explorer in `src/`. The assessment named Next.js; this host serves TanStack Start on the preview port.

- **Coverage Window**: Source-lane article event map — four source lanes (BBC, NPR, The Guardian, Al Jazeera), article events as dots on a shared time axis, cluster connections as bands on hover/selection
- Cluster detail panel with chronological article list
- Source filter toggles
- Refresh data calls `POST /ingest/trigger` and polls status
- Auto-refresh of `/timeline` every 90 seconds
