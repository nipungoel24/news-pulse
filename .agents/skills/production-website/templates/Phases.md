# Phases.md

## Phase 0 — Discovery
Audit repository, routes, stack, content, SEO, console, network, mobile, and deployment.

## Phase 1 — Foundation
Establish design tokens, typography, layout, components, icons, and responsive rules.

## Phase 2 — Site shell
Build header, footer, navigation, mobile menu, sticky behavior, and contact links.

## Phase 3 — Core pages
Implement required pages, custom 404, legal pages, and thank-you flow.

## Phase 4 — Conversion
Implement CTA hierarchy, forms, validation, loading, success, error, and empty states.

## Phase 5 — Trust/local
Add only real case studies, reviews, team assets, maps, directions, and business details.

## Phase 6 — SEO/discovery
Implement titles, descriptions, canonicals, OG, favicon, robots, sitemap, llms, lang, and structured data.

## Phase 7 — Accessibility
Keyboard, focus, semantics, forms, contrast, dialogs, reduced motion, and skip link.

## Phase 8 — Mobile
Eliminate overflow, verify safe areas, touch behavior, responsive typography, and mobile navigation.

## Phase 9 — Performance
Bundles, images, dependencies, source maps, hydration, runtime warnings, and slow-network behavior.

## Phase 10 — Browser QA
Links, CTAs, forms, deep routes, 404, console, network, and critical flows.

## Phase 11 — Deployment
Domain, HTTPS, canonical host, production metadata, analytics, social previews, favicon, and 404.

## Phase 12 — Release review
Run every launch checklist and update Memory.md.
