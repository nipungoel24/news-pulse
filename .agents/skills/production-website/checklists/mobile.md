# Mobile Checklist

- [ ] No horizontal scrolling
- [ ] No clipped content
- [ ] Mobile menu works
- [ ] Sticky header does not cover content
- [ ] Sticky CTA respects safe areas
- [ ] Typography remains readable
- [ ] Forms work with mobile keyboards
- [ ] Touch targets are usable
- [ ] Hover effects do not assume touch
- [ ] Appropriate viewport units
- [ ] Images scale correctly
- [ ] Long text wraps correctly
- [ ] Tested at narrow viewport
- [ ] Real-device verification where available
