# Accessibility Checklist

- [ ] Semantic HTML
- [ ] Heading hierarchy
- [ ] One clear primary H1
- [ ] Keyboard navigation
- [ ] Visible focus
- [ ] Accessible names
- [ ] Labels for form fields
- [ ] Inline errors
- [ ] aria-invalid where needed
- [ ] aria-describedby relationships
- [ ] Dialog focus management
- [ ] Skip-to-content
- [ ] Meaningful alt text
- [ ] Decorative images use empty alt
- [ ] Reduced motion
- [ ] Touch targets are usable
- [ ] Contrast reviewed
- [ ] Paste is not blocked
