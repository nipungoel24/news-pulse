# Rules.md

## Design
- No generic AI aesthetic.
- No purple/multicolor gradients unless justified by the brand.
- No fake proof.
- No emoji UI icons.
- No universal pill controls.
- No unnecessary animation.

## Content
- Never invent factual business claims.
- Never fabricate reviews, metrics, customers, or awards.
- Record missing content as a dependency.

## Accessibility
- Semantic HTML.
- One clear primary H1.
- Keyboard and focus support.
- Proper labels and error relationships.
- Reduced-motion support.
- Usable touch targets.

## SEO
- Unique titles/descriptions.
- Canonicals.
- OG/social metadata.
- Correct lang.
- robots/sitemap/llms.
- Truthful structured data.

## Performance
- Optimize images.
- Analyze bundles.
- Remove dead dependencies/code.
- No public production source maps by default.
- Fix runtime warnings.

## Code
- Follow existing conventions.
- No random files.
- No duplicate constants.
- No secrets in source.
- No debug logs in production.

## Completion
Never claim an unverified requirement is complete.
